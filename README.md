# Integral — Engineering Mathematics MVP

A Vite + React demo for an engineering-math learning product that runs 100% locally in the browser with **no external API calls**.

## Features in this build
- **Major-scoped questions:** When a specific engineering major is selected, only that major's questions are shown in the practice switcher and question bank—other majors' questions are hidden.
- **Learning style selector:** Choose your learning style alongside your engineering major in **My courses** (or in the quick selectors inside **Practice problem**), updating the active question for that major accordingly.
- **Live progress bar updates:** Answering questions correctly increases topic progress bars (`Topic mastery`) and updates mastery status across the workspace.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite (typically `http://localhost:5173`).
